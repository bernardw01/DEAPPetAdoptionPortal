## Status vocabulary

- **Proposed:** awaiting architecture review.
- **Planned:** approved but not implemented.
- **In progress:** implementation has begun.
- **Implemented:** validation evidence satisfies all required criteria.
- **Partial:** some criteria remain open and are named explicitly.
- **Deferred:** intentionally removed from the active sequence.
