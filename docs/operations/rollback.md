# Rollback and Recovery Runbook

Before the first production release, document:

- application rollback procedure;
- database migration compatibility and restore procedure;
- backup location, access controls, and retention;
- recovery-time and recovery-point expectations;
- rehearsal procedure and evidence location;
- post-rollback validation and stakeholder communication.

Do not claim rollback readiness until the procedure has been rehearsed in a
safe environment.
