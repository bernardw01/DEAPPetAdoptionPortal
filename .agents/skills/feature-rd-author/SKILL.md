# Feature RD Author

Read `AGENTS.md`, the PRD, implementation plan, existing Feature RDs, and live
code relevant to the request. Establish requirement traceability, existing
behavior, scope, non-goals, architecture, cross-cutting concerns, acceptance
criteria, expected tests, rollout, rollback, and open decisions. Use
`docs/features/TEMPLATE-feature-rd.md`. Leave criteria unchecked and request
human approval before implementation.
